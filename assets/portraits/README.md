# Fictional family portraits

These eight original SVG illustrations depict the game’s **fictional characters**, not actual historical people. They are newly drawn game artwork, not primary sources, archival portraits, or evidence about an individual’s appearance.

- `grandma.svg`: June / Nookomis, present-day grandmother.
- `nora.svg`: Waaban, present-day teenage cousin.
- `rose.svg`: Waabigwan, fictional adult ancestor in 1926.
- `leena.svg`: Niibin, present-day adult relative.
- `eli.svg`: Ishkode, fictional adult ancestor in 1926.
- `dan.svg`: Aki, present-day adult relative.
- `ada.svg`: Giizhig, fictional older adult ancestor in 1926.
- `tess.svg`: Biboon, present-day aunt.

Ordinary work clothes and seasonal clothing distinguish eras. The portraits do not present ceremonial clothing, sacred designs, or a claimed traditional naming practice. Local community and classroom review remains pending.

Each file has an editable 240 × 240 viewBox, an accessible title and description, vector paths and a small shared color palette. Edit SVG colors and paths directly or open the files in a vector editor. The internal English keys preserve the game’s existing character identifiers; displayed names come from `src/content.js`.
